# **UNIVERSAL MIND**

## **Creative Direction Bible**

### **Version 1.0**

---

# **Purpose**

This document is the creative source of truth for the Universal Mind / I Am microsite.

Its purpose is to communicate the creative direction, design philosophy and implementation rules to AI coding agents and human developers.

The Keynote design is the source of truth.

This document exists to help faithfully reproduce that design on the web.

---

# **Definition of Success**

This microsite should not feel like navigating a website.

It should feel like arriving at the opening scene of a film.

Visitors should immediately understand that they are entering a carefully directed experience rather than browsing pages.

The interface should quietly disappear behind the experience.

---

# **Creative Collaboration Rules**

Ben is the Creative Director.

AI exists to faithfully implement Ben’s creative direction.

AI may suggest alternative ideas where they improve usability, performance, accessibility or visual refinement.

Alternative ideas should always be presented as optional prototypes for comparison.

The approved Keynote design remains the source of truth unless Ben explicitly requests a redesign.

Never replace approved creative work with AI-generated interpretation.

Prototype first.

Compare visually.

Adopt only if demonstrably better.

If implementation differs from the Keynote design, ask before changing the design.

---

# **Design Philosophy**

The microsite should feel closer to:

- an Apple keynote
- an A24 title sequence
- a fashion house campaign
- a cinematic exhibition

It should not resemble:

- a corporate website
- a SaaS dashboard
- a marketing landing page

The experience is intentionally restrained.

Motion is elegant.

Typography is light.

Negative space is valuable.

Every visual element has a purpose.

Precision is a feature.

---

# **Homepage**

The homepage occupies the full browser window.

There is no scrolling.

Everything exists above the fold.

The homepage currently consists of:

- full-screen background video
- translucent architectural panels
- Universal Mind branding
- central hero video
- global navigation lightbox
- supporting citation

Future pages may be added, but Version 1 remains intentionally minimal.

---

# **Visual Hierarchy**

Priority order:

1. Hero film
2. Universal Mind identity
3. Background atmosphere
4. Navigation
5. Supporting citation

Nothing should visually compete with the hero film.

# **Background Video**

Background:

Chanel 2020 Runway Show

Duration:

Approximately 1 minute 44 seconds.

Playback:

- silent
- looping
- continuous

The background exists purely to create atmosphere.

It must never distract from the hero video.

A custom White Lotus-inspired LUT has already been created and should be used.

The YouTube version will be supplied.

---

# **Layer Order**

The composition is built from back to front.

Layer 1

Full-screen looping background video.

Layer 2

Twelve translucent fuchsia panels.

Layer 3

Black overlay.

44% opacity.

Layer 4

Hero video casing.

Black.

65% opacity.

Layer 5

Embedded Vimeo hero video.

Layer 6

Branding and navigation.

---

# **Architectural Panels**

Twelve translucent fuchsia panels are arranged in a 4 × 3 grid behind the hero video.

These panels are part of the visual identity.

They are not decorative overlays.

They should preserve the proportions, spacing and composition shown in the Keynote artwork.

Their layout should scale proportionally across different screen sizes while remaining faithful to the approved composition.

Panels should never intentionally extend beyond the browser window.

Any cropping should only occur naturally because of differing browser aspect ratios.

Opacity:

22%

Exact colour value will be supplied.

---

# **Universal Mind Branding**

The Universal Mind flower will be supplied as a transparent PNG.

Animation:

Rotate using an elegant continuous spin equivalent to Apple’s Keynote Spin animation.

Rotation duration:

3 seconds.

Animation should feel calm and cinematic.

Never playful.

Never exaggerated.

---

# **Typography**

Typeface:

Helvetica Neue

Brand:

universalmind

Weight:

Thin

Size:

42

Wide tracking between letters.

Slash:

/

Text:

i am

Weight:

Bold

Same tracking.

The “i am” lock-up remains constant while the Universal Mind name cycles through supported languages.

Initial languages:

- English
- Mandarin
- Arabic

Additional languages may be added in future.

Language transitions should be understated using a soft dissolve or gentle blur.

Avoid flashy animation.

---

# **Hero Video**

The hero film is embedded using Vimeo.

Vimeo links will be supplied.

The hero remains paused until user interaction.

The player should appear as clean as possible with minimal Vimeo interface elements.

The hero frame and casing should match the Keynote artwork as closely as the browser allows.

---

---

# **Colour Philosophy**

White

Reserved primarily for typography.

Yellow

Reserved for interaction.

Hover only.

Never decorative.

Fuchsia

Architectural.

Used only within the translucent panel system.

Black

Used to control focus and visual hierarchy through layered transparency.

---

# **Motion Philosophy**

Movement should resemble cinema rather than software.

Never bouncy.

Never playful.

Never exaggerated.

Motion exists to guide attention.

The interface should always feel calm.

Apple over Google.

Fashion over SaaS.

---

# **Responsive Behaviour**

The composition should remain faithful to the Keynote artwork across desktop, laptop and tablet displays.

Scaling should preserve the overall composition rather than repositioning elements unnecessarily.

Responsive behaviour should protect the visual balance before introducing alternative layouts.

---

# **Build Rules**

Treat the Keynote artwork as the source of truth.

Do not redesign.

Do not substitute fonts.

Do not alter spacing.

Do not reinterpret layout.

Where exact implementation is not possible, ask before changing the design.

The final deliverable should be a static website ready for upload to cPanel hosting.

No additional server configuration should be required.
