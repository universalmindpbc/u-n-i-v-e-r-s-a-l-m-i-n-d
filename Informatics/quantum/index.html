Connected methods and future routes

CUDA-Q specifies the simulation; qBraid provides the GPU route for compatible compiled programs. Amazon Braket routes the analog program to QuEra Aquila. D-Wave Leap is a separate annealing route for future validated templates. Each route retains its own model and execution receipt.

Names identify the technologies in the workflow; no partnership or endorsement is implied.
